## Project Description

A simple command-line Line Editor developed in C. It allows users to create, view, insert, delete, modify, save, and load lines of a text document.

## Data Structure

The project uses an array of strings to store document lines.

## Features

- Insert a line
- Delete a line
- Display document
- Save document
- Load document
- Help command
- Quit command

## Technologies Used

- C
- GCC
- Visual Studio Code
- Git
- GitHub
